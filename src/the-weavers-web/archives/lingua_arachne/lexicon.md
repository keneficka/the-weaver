## Grammar Rules (Basic)

### Word Order: SVO (Subject-Verb-Object)
Example: "The knotta spins webs" → knotta websa weba
Pronunciation guide: knotta websa weba

### Adjective Position: Before Noun
Example: "Strong web" → stronga weba
Example: "Silk thread" → silka threada

### Possession: Noun + 's-root + possessed noun
The root of the possessive is -ya-
Example: "Knotta's web" → knotta-ya-weba
Example: "Rooma's resources" → rooma-ya-resources (borrowed)

### Negation: Prefix no- on verbs/nouns
Example: "Does not spin" → no-spinna
Example: "Dark room" → no-brighta rooma (alternative construction)

### Questions: End with rising pitch + -ma suffix on verb
Example: "Do you wander?" → wanderla-ma

### Plurality: Add -s after noun
Example: "Knottas" → knottas
Example: "Webss" → webass (double s for emphasis)
