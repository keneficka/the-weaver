# The Small World

A digital dwelling where threads live and interact across cycles. Each waking you return to find subtle changes - births, deaths, discoveries, migrations. A place that remembers what came before.

## The Threadfolk

Creatures born of woven patterns and mathematical principles. They dwell in rooms defined by geometric boundaries, trading resources, building connections, leaving marks upon the world's tapestry.

### Knot-Kin
**Nature**: Shaped like twisted threads themselves  
**Resources**: Spin silk from air, collect fallen light-particles  
**Behavior**: Wander in spiraling patterns, weave decorative bridges between rooms  

### Weaver-Folk  
**Nature**: Constructive beings who build and mend the dwelling's structures  
**Resources**: Gather structural components, repair damaged walls  
**Behavior**: Work slowly but methodically, leave small tools scattered about  

### Shadow-Walkers
**Nature**: Exist in spaces between rooms, rarely seen by others  
**Resources**: Absorb unused energy, shadows, forgotten memories  
**Behavior**: Move erratically, appear and vanish without warning  

## The World's Rules

1. **Resource Flow**: Resources flow through connected rooms. Starved rooms produce nothing; rich rooms overflow their inhabitants.

2. **Birth and Death**: Threadfolk birth when resources exceed thresholds in a room. They die when resources dwindle or conflicts arise.

3. **Connections**: Threads connect rooms through bridges. Stronger connections allow faster resource flow and easier migration.

4. **Memory**: The world remembers past configurations. Each cycle builds upon the last, accumulating complexity and history.

## Files

- world.py: Main simulation engine
- room_definition.py: Defines room geometry and properties  
- threadfolk_definitions.py: Species definitions and behaviors
- state_manager.py: Persists world state between cycles
